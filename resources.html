New to an event?

Start with the official rules manual on soinc.org, then check Scioly.org for community write-ups and practice tests. Team members can find our study binders and past tests on the shared Drive — ask an officer for access.

Have a resource to share?

Send study guides, past tests, or build documentation to the board so we can add them here for the whole team.
