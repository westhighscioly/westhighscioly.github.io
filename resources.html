Tools We Use

Practice & logistics tools

  • Quizlet — flashcard sets for ID and vocab-heavy events
  • Google Drive — shared binders, slides, and past tests
  • Band — team announcements and practice scheduling
  • Tournament host sites (e.g. Tabroom, Duosmium archives) — past tests and results
New to an event? Start with the official rules manual on soinc.org, then check Scioly.org for community write-ups and practice tests. Team members can find our study binders and past tests on the shared Drive — ask an officer for access.

Have a resource to share?

Send study guides, past tests, or build documentation to the board so we can add them here for the whole team.
